# Itsy Web logo brief

Itsy Web is the working name for the existing Flea website system. The audience knows HTML and CSS and wants templates, clean URLs, local development, deployment and HTTPS without a frontend toolchain. Snips and apps are optional documentation topics, not the brand promise.

Scope: logo, wordmark, favicon/touch icons and sharing artwork. Preserve the current site layout, copy, navy (#142b43), ice (#a4dbff) and pale ground (#f5f9ff). Make the mark identifiable at browser-tab size and the wordmark readable in the current header. The name is exactly “Itsy Web”. Avoid generic globes, network nodes, shields, rockets, gradients, glossy 3D and a pair of code brackets with no ownable idea.

Three scoped concept previews: One thread (an i/w ligature made from a continuous strand), Itsy the builder (a tiny graphic spider with poised, purposeful legs), The slot (header/body/footer assembled into an abstract i). The first is the recommendation for connecting the web name to a compact, grown-up developer identity. The spider is a more personable alternative; the slot is a more architectural one. Direction approval precedes production integration. Deployment to https://itsy.fleacms.com is explicitly authorized by the user.

Reference inspected: site/css/theme.css, current site/main.layout.html and previous homepage render. These supply palette and display-size constraints; the old Flea mark is not an approved Itsy Web identity.

## Round 2 — approved typography, new marks

The user chose the first concept as the direction for further exploration, especially its typography. Preserve the original rounded Itsy Web wordmark, letter shapes, weight and spacing exactly. The mark is still unresolved. Explore three alternate symbols in the same navy/ice palette: a compact woven loop, a folded-page symbol, and a more upright i/w ligature. These are concept previews; no mark is approved for production yet. The previous browser board closed without a choice, so this round is shown directly in chat using an inline image comparison.

## Round 3 — woven-loop variations

The user requested three variations on the first mark from round 2: the woven loop. Keep the approved rounded wordmark, colors and presentation fixed. Vary only the loop’s proportions, crossing and silhouette. Explore a tighter upright loop, a softer open loop and a compact angular loop. These remain previews awaiting a selected production mark.

## Production approval

The user prefers the original woven loop from round 2, not one of the round-3 refinements. Approved source: `.impeccable/mocks/decision/round-2/loop.png`. Preserve its original rounded lettering. Apply this identity throughout the updated site and deploy it to `https://itsy.fleacms.com`. No further direction choice is pending.

## Joined brand name

The user requested ItsyWeb as one word across the website and logo. Preserve the approved mark and original letterforms; close only the word space between Itsy and Web. Historical candidate images and exact generator prompts remain as provenance.
