# Coding agent instructions

This is an ItsyWeb project.
Edit the HTML and CSS in `site/`.
{icon file}site/index.html
<h1>Hello, web.</h1>
<p>A small website, in plain HTML.</p>
{render /navigation}

Open the site folder in your editor or coding agent. Generated projects include AGENTS.md and portable skills for site authoring, design, and common additions. Give the agent a concrete task, then review the files and preview the result.

The files stay ordinary HTML, CSS and JSON. The instructions stay in Git, outside the public website. No plugin or account is needed to read them.

Work with your coding agent {icon arrow-up-right}

Skip the build pipeline.
Keep the HTML.

You wanted to make a website, not maintain a toolchain. Write ordinary HTML and CSS, then add the shared pieces a small site needs.

{icon file}site/main.layout.html
<header>{render /navigation}</header>
<main>{slot}</main>
<footer>Made by our studio.</footer>

A shared header shouldn’t require a framework.

Put shared markup in a layout or partial and change it once. Each page fills the layout’s {slot}. The server puts it together when someone visits; there is no static site to generate first.

The website still needs to run somewhere.

Writing the HTML is only part of the job. ItsyWeb includes the local tools, the web server and the way to deploy. One executable, with no Go, Node or Python runtime or database to install by hand.

Set up and deploy {icon arrow-up-right}
Preview as you work
itsy dev reloads the browser when you save. Use LAN mode to check the site on your phone.
Set up an Ubuntu host
Bring a supported Ubuntu LTS server, SSH access and a domain. itsy setup installs the bundled web server.
Deploy a Git branch
Publish committed files over SSH. Branches can have different destinations, and one server can host several sites.
Keep HTTPS running
With DNS pointing to your server and ports 80 and 443 open, ItsyWeb requests and renews Let’s Encrypt certificates. Optional www redirects are included.
Back up and recover
Download a site backup or return to an earlier code release with the same tool. Backups and recovery
