# Coding agent instructions

This is an Itsy project.
Edit the HTML and CSS in `site/`.
{icon file}site/index.html
{render /navigation}
<h1>Hello, web.</h1>
<p>A small website, in plain HTML.</p>

Open the site folder in your editor or coding agent. Generated projects include AGENTS.md and portable skills for site authoring, design, and common additions. Give the agent a concrete task, then review the files and preview the result.

The files stay ordinary HTML, CSS and JSON. The instructions stay in Git, outside the public website. No plugin or account is needed to read them.

Work with your coding agent {icon arrow-up-right}

The website still needs to run somewhere.

Writing the HTML is only part of the job. Itsy includes the local tools, Itsy Server and the way to deploy. One executable, with no Go, Node or Python runtime or database to install by hand.

Set up and deploy {icon arrow-up-right}
Preview as you work
itsy dev reloads the browser when you save. Use LAN mode to check the site on your phone.
Set up an Ubuntu host
Bring a supported Ubuntu LTS server, SSH access and a domain. itsy setup installs Itsy Server.
Deploy a Git branch
Publish committed files over SSH. Branches can have different destinations, and one Itsy Server can host several sites.
Keep HTTPS running
With DNS pointing to your server and ports 80 and 443 open, Itsy Server requests and renews Let’s Encrypt certificates. Optional www redirects are included.
Back up and recover
Download a site backup or return to an earlier code release with the same tool. Backups and recovery
