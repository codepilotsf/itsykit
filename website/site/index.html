KEEP WRITING HTML

A shared header shouldn't require a framework.

You know HTML and CSS. You just want a header you can change once, a footer you don't have to paste into every page, and URLs without .html on the end.

ItsyWeb's server adds layouts, partials, variables, loops and conditions to your HTML files. Write a page, put the shared markup in a layout, and let the server put them together. There's no static site to generate first.

Create site/about.html. Link to /about. Keep styling it with CSS.

Learn the template syntax ↗
layouts + pagesHTML
<!-- site/main.layout.html -->
<header>{render /navigation}</header>
<main>{slot}</main>
<footer>Made by our studio.</footer>

<!-- site/about.html → /about -->
<h1>About our studio</h1>
<p>We make things for the web.</p>
One layout for the shared markup. A partial in site/_navigation.html. Your page goes in {slot}.

The website still needs to run somewhere.

Writing the HTML is only part of the job. ItsyWeb includes the local tools, the web server and the way to deploy. You don't have to assemble the rest yourself.

  • No frontend build step

    Edit HTML and CSS directly. No bundler, generated output directory or Node toolchain between your files and the website.

  • Preview as you work

    itsy dev serves the site locally and reloads the browser when you save. Use LAN mode to check it on your phone.

  • Set up the server

    Point itsy setup at a blank Ubuntu host over SSH. It installs the bundled web server. No runtime or database to install by hand.

  • Deploy over SSH

    Publish a committed Git branch with itsy deploy. Different branches can have different destinations, and one server can host multiple sites.

  • HTTPS without the chores

    With your domain pointing at the server and ports 80 and 443 open, ItsyWeb requests and renews Let's Encrypt certificates and can redirect www.

  • Back up and roll back

    Download a site backup or return to an earlier code release. Recovery commands are part of the same tool.

Read Getting Started ↗
  1. 01

    Install

    One executable. No language runtime to install first.

    curl -fsSL https://itsyweb.dev/install.sh | bash
  2. 02

    Create a site

    Start with HTML and CSS files you can open and understand.

    itsy new my-site
cd my-site
  3. 03

    Write and preview

    Edit a page or layout. Save and see the browser reload.

    itsy dev
  4. 04

    Set up your server

    Install the bundled server on your Ubuntu host over SSH.

    itsy setup
  5. 05

    Deploy

    Commit your changes, publish the branch and enable HTTPS.

    itsy deploy
