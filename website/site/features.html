Small by design.

For developers who want to write HTML, and admins who want to change their website without learning a page builder.

Plain files

HTML pages, reusable partials, custom layouts, JSON content, and CSS. Keep the site in Git.

Inline editing

Rich text, links, page titles, and descriptions. Preview changes in place, then save or cancel.

Multisnips

Repeat developer-defined cards. Add entries in a side panel, duplicate, remove, and reorder them.

Theme controls

Adjust colors, fonts, fluid typography, and spacing with a live preview. The source stays in theme.css.

Email

Passwordless sign-in and simple contact forms through Resend, with developer-editable email templates.

Deployment

Git-backed deployments over SSH, bundled Linux servers, HTTPS support, and conflict-aware content synchronization.

Photos

Upload JPEG and PNG photos, update alternative text, and choose photos for repeatable cards. Processing runs in Go.

Recovery

Code rollback that preserves admin edits, site backups and restore, and executable updates with failure recovery.

Before version one

Flea is still in development. Broader browser testing, live server recovery verification, managed video integration and public distribution are pending. Don't treat this preview as a production-readiness guarantee.
