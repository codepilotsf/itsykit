About ItsyWeb and support

ItsyWeb is for websites you want to build with HTML and CSS, with the tools to run them included.

A small website, in ordinary files

Write pages, share layouts and partials, and publish to a server you control. Add Contact or Blog when the site needs them. Custom behavior belongs in a managed app.

The binaries are free to use without an account or license key. The source repository is private.

Get help

Check the site or look up a command's options:

itsy status
itsy deploy --help

If you need help with a test release, contact the person who invited you. Include your operating system, itsy version, the command, and its error message. Leave out credentials and sign-in codes.
