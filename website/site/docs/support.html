About ItsyWeb and support

Understand where ItsyWeb fits, its current limits, and how to report a problem.

HTML doesn't need a build pipeline.

You want to write HTML and CSS. Then you need the same navigation on every page, a shared footer and URLs without .html. That shouldn't mean adopting a framework or generating a second copy of your website.

ItsyWeb is a web server that understands HTML with a few extra instructions. Layouts wrap your pages, partials reuse markup, and variables, loops and conditions let you work with settings and JSON data. The server assembles the page when it serves it. You keep writing HTML.

It also includes the tools to run the site: local development with live reload, Ubuntu server setup over SSH, deployment, automatic HTTPS, backups and code rollback. There is no frontend build step or language runtime to install.

Start with the Getting Started tutorial. You can use the server and deployment tools without setting up an editor or enabling an app. Those optional features are documented separately.

Where ItsyWeb fits

Use ItsyWeb for websites you would otherwise build in plain HTML, with shared templates and the tools to run them. It does not turn HTML into a general application framework or provide an ecommerce platform.

  • No general content field schemas or general-purpose form backend. Templates do not execute arbitrary server-side application code; custom logic belongs in a managed app.
  • Custom apps are managed local executables only: no remote services, package registry or public SDK. Each app owns and protects its own storage.
  • No video transcoding or video fields in collections.
  • No content revision-history interface. Use the backup and recovery commands.
  • Editable rich text is sanitized and does not accept unrestricted HTML. This restriction applies to the optional content editor; your source templates remain developer-authored HTML.
  • Downloads currently cover Apple Silicon macOS and x86-64 Linux. Clean-machine testing is in progress.

The source repository is private. The binaries are free to use, without an account or license key.

Need a hand?

Start with itsy status to check your site and itsy <command> --help for a command's options.

If you're testing ItsyWeb, send feedback to the person who invited you. Include your operating system, processor, ItsyWeb version, the command you ran and the exact error. Leave out credentials, sign-in codes and private runtime files.
