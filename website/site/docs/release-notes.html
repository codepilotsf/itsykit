Release notes

Changes in the published releases, newest first.

0.21.0 · November 14, 2026

Flea becomes ItsyWeb. New sites use itsy.config.json and itsy/; existing names remain supported. Deployment protocol 29 requires a server update. The app protocol remains 2.

See Installation and updates for the current upgrade steps.

0.20 releases

0.20.5 · November 9, 2026

Applies navy-on-light branding across the website and generated sites, preserving existing custom branding.

0.20.4 · November 9, 2026

Fixes the favicon and touch-icon palette in light and dark browser themes.

0.20.3 · November 9, 2026

Adds the approved filled mascot to new sites and development diagnostics.

0.20.2 · November 2, 2026

Updates bundled logos, favicons, and sharing artwork without replacing custom site branding.

0.20.1 · November 2, 2026

Packaging respects TMPDIR and reports temporary-storage problems more clearly.

0.20.0 · October 30, 2026

Adds exact 301 redirects and optional sitemap, robots, canonical, and page-exclusion support. Requires server protocol 28.

0.19 to 0.10

0.19.0 · October 24, 2026

Adds persistent indexing policy for individual hostnames. Requires server protocol 27.

0.18.0 · October 21, 2026

Supports itsy new . and directory paths. Discontinues Linux ARM64 CLI downloads while retaining ARM64 server support and previous downloads.

0.17.0 · October 18, 2026

Adds managed local apps and app-owned sessions using protocol 2. Requires server protocol 26.

0.16.1 · October 18, 2026

Fixes literal brace groups and JSON in templates while preserving directive validation and escaping.

0.16.0 · October 13, 2026

Adds hostname and Tailscale access in LAN mode, automatic dev-port selection, and clearer server-update progress.

0.15.1 · October 13, 2026

Bundles focused Blog and Contact setup skills in new sites.

0.15.0 · October 13, 2026

Adds optional Blog with drafts, publishing, rich text, and cover photos. Requires server protocol 25.

0.14.0 · October 13, 2026

Removes browser Theme editing and theme-sync flags. Styles now come from committed CSS; preserve older live CSS customizations before upgrading.

0.13.0 · October 12, 2026

Status shows local validation first, then checks the branch’s saved deployment.

0.12.0 · October 12, 2026

Introduces the Linux ARM64 CLI download, later discontinued in 0.18.0.

0.11.0 · October 12, 2026

New sites receive an initial Git commit and instructions for connecting a remote.

0.10.0 · October 5, 2026

Renames the site listing command to itsy server list and simplifies server and site selection.
