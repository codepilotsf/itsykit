Release notes

Read the changes and upgrade requirements for each published release.

Release notes

0.21.0 · November 14, 2026

Flea is now ItsyWeb, with the itsy CLI and new itsy.config.json/itsy/ site paths. Existing site filenames, sessions, custom branding and live content remain compatible. The old command prints a rename notice and stops, except flea update, which installs itsy. Deployment protocol 29 requires an explicit server update; the app protocol stays 2. Canonical downloads use itsy-* names, with retained flea-* aliases for existing updaters.

0.20.5 · November 9, 2026

The approved navy mark now appears on light backgrounds across icons, the website header/footer, sharing artwork and generated sites. The light website header has matching navy navigation and a readable sticky scroll treatment. Existing customer branding and protocols remain unchanged.

0.20.4 · November 9, 2026

Favicons and touch icons now keep the same white mark on a solid navy background as the website header, in both light and dark browser themes. New sites receive the matching icons. Protocols and existing customer branding are unchanged.

0.20.3 · November 9, 2026

Little Skip now uses the approved filled treatment, with three filled body segments and a friendly face. Updated SVG logos, favicons and touch icons ship in new sites and development diagnostics. Existing sites retain their own branding. The Nunito lettering and deployment/app protocols remain unchanged.

0.20.2 · November 2, 2026

Updated SVG logos and favicons appear throughout the website, docs, generated sites and development diagnostics. Existing sites keep their custom branding. Deployment protocol stays 28; app protocol stays 2.

0.20.1 · November 2, 2026

Local deployment, server setup and Mac installer packaging now respect TMPDIR. Each invocation keeps a private scratch directory and removes it on completion, ordinary errors and handled cancellation. Storage errors identify the temporary location and explain how to choose another one. The release client also removes its own smoke-test directory. Deployment protocol stays 28; app protocol stays 2.

0.20.0 · October 30, 2026

Adds exact 301 migration redirects in the top-level redirects config object. List legacy extensions and trailing-slash paths explicitly, keep or replace queries, and point directly to existing local public pages or assets. Validation rejects unsafe paths, route conflicts, missing destinations, chains and loops. The Itsy site skill and brochure import workflow can inventory old URLs, prepare mappings and verify responses. Deployment protocol moves to 28; update the CLI and shared server together. The optional seo settings add snapshot-generated sitemap/robots discovery, missing canonicals and exact noindex page exclusions while preserving custom files and staging host policy. App protocol remains 2.

0.19.0 · October 24, 2026

Adds exact-host indexing control through itsy server indexing. Configure staging once and retain X-Robots-Tag: noindex, nofollow across deploy, sync, code rollback and site restore while serving the same website source on other hosts. List/status show effective policies and static robots.txt crawl-block warnings. No templates or robots.txt files are rewritten. Deployment protocol moves to 27; matching clients and servers are required, with a separate explicit server update. App protocol remains 2.

0.18.0 · October 21, 2026

Create a site in your current empty folder with itsy new ., or pass a relative or absolute directory path. Existing directories must be completely empty, including hidden files and .git; Itsy refuses nonempty directories without overwriting files. Folder-based naming and the initial Git commit are preserved. Linux ARM64 CLI downloads are discontinued; Apple Silicon macOS and x86-64 Linux CLIs retain ARM64 Linux server deployment support. Previously published downloads remain available. Starter agent guidance uses the globally installed Impeccable skill.

0.17.0 · October 18, 2026

Adds custom managed apps: register a validated local executable under apps.<name> and Itsy supervises it with the Itsy App Protocol version 2. Apps can own server-side sessions through Itsy’s isolated __Host- cookie and the X-Itsy-Session header, with state kept in stable per-site runtime storage. App output is data, never template source. Deployment protocol moves to 26 with no fallback: update the server with itsy update-server before deploying a package-bearing site. Existing sites keep their current releases until redeployed.

0.16.1 · October 18, 2026

Ordinary literal brace groups and raw JSON now work in template text and attributes. Recognizable malformed commands retain useful errors, and normal interpolation and contextual escaping remain active. Use &#123;app.site_name&#125; to display exact Itsy syntax literally. Update both the local CLI and production server to use the fix.

0.16.0 · October 13, 2026

LAN dev accepts this computer's hostname and local alias, including connections over Tailscale IPv4. Exact Host/port, peer, Origin and CSRF checks remain in place. Default dev tries the next available port when 3000 is occupied and explains the selected URL. Server updates and recovery show terminal progress after confirmation, with plain output when redirected.

0.15.1 · October 13, 2026

New sites include focused Blog and Contact setup skills, with request routing, template values and content/form conventions. Existing projects can adopt the instructions without changing their layouts. Available through the public installer and itsy update.

0.15.0 · October 13, 2026

Adds optional Blog with drafts, explicit Publish/Unpublish, rich text, cover photos and a JSON format for agents. Public templates receive published posts only. Blog requires explicit site setup and server protocol 25.

0.14.0 · October 13, 2026

Removes browser Theme editing, CSS overlays and theme synchronization. CSS remains in source and is published by normal deployment. The --with-theme, --theme-only and --snips-only flags have been removed. Older servers need reviewed upgrade preparation as described above; saved CSS customizations must be preserved before removing obsolete host mappings.

0.13.0 · October 12, 2026

itsy status now prints local validation, site counts and Git state first, then automatically checks the current branch’s configured deployment. Code, content and theme are reported separately, with change direction when a pull baseline exists. Status remains read-only; no remote flag is needed.

0.12.0 · October 12, 2026

Adds a Linux ARM64 CLI download alongside Apple Silicon Mac and Linux x86-64. The installer detects aarch64 and verifies its checksum and version. All CLIs still bundle both Linux server architectures. Missing-download errors now name the release and selected platform.

0.11.0 · October 12, 2026

itsy new now creates an Initial site commit on main and prints commands to connect and push to a remote repository. It respects your Git identity, hooks and signing settings. A failed commit preserves the site with instructions to retry; --skip-git skips Git setup. Itsy does not create or configure a remote repository automatically.

0.10.0 · October 5, 2026

Itsy renames itsy server sites to itsy server list with no alias. Both itsy server list and itsy server remove now ask for the server login (for example root@itsyweb.dev) when you omit the SSH target, and itsy server remove without a site name lists the managed sites and asks you to choose one by its exact name before the existing confirmation. Listing shows each site's name and branch, then HTTPS domains, then HTTP-only domains, then redirects. Removal is unchanged: the list is read-only, removal only unregisters routing and deletes no files, and it restarts the shared server, so other sites are briefly unavailable. These commands need a current server runtime. Run itsy update for the CLI.

0.9.0 · October 5, 2026

Itsy now bundles the Contact app and adds server-wide site administration with itsy server sites and itsy server remove. Enable a form under apps.contact with a mount and recipient; it posts with an explicit CSRF control to the mount, and success redirects to the mount-relative thank-you page. This replaces the top-level contact settings and the /_itsy/contact route, and deployment requires protocol 23; there is no alias or automatic migration, so update the server and existing sites together. Large static assets and managed photos now stream from disk instead of loading fully into memory. Run itsy update for the CLI, then update the shared server separately with itsy update-server.

0.8.1 · October 3, 2026

Starting Itsy no longer duplicates its runtime and media rules in .gitignore when other entries follow them. Existing file contents are preserved. Run itsy update to install the fix.

0.8.0 · October 3, 2026

The editing row slides beneath the top bar and disappears outside Edit. Theme slides from the right and fills the available height. Both respect reduced motion. Existing sites must update site/admin/_toolbar.html from the current starter alongside the executable; preserve custom layouts. Run itsy update for the CLI, and update the server separately.

0.7.1 · October 3, 2026

Routine HTTPS deployments now say “Checking site health and HTTPS...” instead of repeating certificate setup instructions. First-time HTTPS enablement still shows DNS and port guidance; certificate verification and renewal are unchanged. Run itsy update to install 0.7.1.

0.7.0 · October 3, 2026

Bundled agent skills now guide substantial imports and redesigns through two design directions and a sample-page review before the full build. Brochure imports also cover portfolio and artist sites, with clearer media, gallery and editing guidance. Release downloads are served from a separate disk-backed store, so website deployments no longer carry all previous binaries.

0.6.2 · October 1, 2026

New sites now bundle a second agent skill, itsy-site, for building or redesigning a site for one real local business, alongside the existing import-brochure skill.

0.6.1 · October 1, 2026

Running itsy dev again gracefully replaces the same site’s dev server, including LAN mode and port changes. Pull and reset stay protected. Crashed dev processes no longer leave a blocking control socket.

Stop any dev process started with an older binary once; subsequent starts replace it automatically. Remote servers remain a separate, explicit update.

0.6.0 · October 1, 2026

Test release. On the first itsy dev, Itsy explains the optional email for an admin who can sign in and edit, points to itsy admin if you skip it, and only asks once. User-facing copy now says "admin", and the busy message for dev, pull and reset is clearer.

0.5.0 · September 29, 2026

Test the full dev site on other devices with itsy dev --lan or -l. Local startup links now use localhost. Page saves update in place without reloading fonts or the page, and Cancel returns to the latest successful save. See network testing for sign-in, preview and security details.

0.4.1 · September 29, 2026

Shorter new-site output: itsy new now finishes with the local development instructions.

0.3.0 · September 29, 2026

The first public test release for Apple Silicon macOS and x86-64 Linux. Install with one command, then use itsy update for future CLI releases.

Includes plain-file sites, on-page text and media editing, repeatable collections, theme controls, local email previews, SSH deployment and backup/recovery commands. This is an early release; please test on a small site before relying on it for production work.
