CSS and icons

Style your site with CSS and the included Prewind utilities. No build command needed.

Your styles

Use site/css/theme.css for colors, fonts, and spacing tokens. Put shared rules inside the existing @layer styles block in site/css/global.css:

a {
  text-underline-offset: .2em;
}

h1 {
  color: var(--brand-1);
}

Save while dev is running to see the changes. Normal deployment publishes your committed CSS.

Prewind utilities

The generated site includes Prewind 1.3.1. Start with global styles, then use utilities for individual layout and spacing adjustments:

<section class="container py-xl">
  <h1>Visit the bookshop</h1>
  <p class="text-lg">Find your next read.</p>
</section>

container provides the page width and padding. Sizes such as sm, md, and lg follow the theme's fluid scale.
