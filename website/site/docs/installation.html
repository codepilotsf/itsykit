Installation and updates

Install a supported CLI, update an existing installation, and check version requirements.

Install ItsyWeb

The command is itsy. Site settings live in itsy.config.json, and downloads are served from itsyweb.dev.

For Apple Silicon Macs and x86-64 Linux. Open Terminal and run:

curl -fsSL https://itsyweb.dev/install.sh | bash

The installer downloads the matching executable, checks its SHA-256 checksum and installs it to ~/.local/bin/itsy. No sudo and no extra runtime such as Go, Node or Python is required. It does not change your shell profile.

Use the installed copy in this terminal and check the version:

export PATH="$HOME/.local/bin:$PATH"
itsy version

If needed, add that PATH line to your shell profile for future terminals. Then follow the Getting Started tutorial.

0.21.0 is the current public test release. Downloads cover Apple Silicon macOS and x86-64 Linux. Both CLIs can deploy to x86-64 and ARM64 Linux servers. Intel Mac and Linux ARM64 CLI downloads are not included; previously published downloads remain available at their versioned URLs. The Mac binary is ad-hoc signed, not notarized, and clean-machine testing is still in progress.

Deployment protocol is 29 and the Itsy App Protocol is version 2. Update the local CLI with itsy update. Update an existing server separately with itsy update-server before deployment or host administration; updating the CLI does not upgrade the host. See release notes for changes in this version.

Flea is now ItsyWeb. The command is itsy. Existing Flea users can run flea update twice, or use the installer above, to install the new command. Other flea commands show the rename notice and stop. Existing .flea.config.json and flea/ files continue to work; new sites use itsy.config.json and itsy/. Update an older server explicitly with itsy update-server before deploying the new layout.

You can read the installer before running it, or download the Mac binary, Linux x86-64 binary and checksums directly.

A site needs no frontend build pipeline or database. The CLI is a single binary, and the server needs nothing installed by hand either. Deployment uses Git and SSH; see Set up the server.

Keep ItsyWeb up to date

Update your installed CLI with:

itsy update

ItsyWeb verifies the downloaded checksum and version before replacing the executable. A local update does not update your remote host. From a configured site, explicitly run:

itsy update-server

After confirmation, a terminal spinner shows that the update is running. Redirected output uses plain progress text; animation yields to SSH diagnostics and interactive sudo prompts. Successful updates print a completion message. Server updates affect every site on that host and ask before restarting it. Keep backups and check compatibility first. An interrupted update can be recovered with itsy update-server --recover.
