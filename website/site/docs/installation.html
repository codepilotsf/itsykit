ItsyWeb Guides

Installation and updates

Install the CLI once, then use it to create, preview, and publish your sites.

Install

Downloads support Apple Silicon macOS and x86-64 Linux.

curl -fsSL https://itsyweb.dev/install.sh | bash

Run this command in Bash or Zsh. It checks the download and installs itsy in ~/.local/bin. The installer configures PATH in your shell's startup files, preserving their existing contents. Open a new terminal when it finishes, then create your first site. To keep using this terminal, run the optional PATH command printed by the installer.

For a different directory, run export ITSY_INSTALL_DIR="/absolute/path" first. For other shells or startup files the installer cannot update, follow its diagnostic to finish setup. No Go, Node, or database is needed to run ItsyWeb.

You can also download the Mac binary, Linux binary, and checksums directly.

0.22.0 is the current public test release. The Mac binary is ad-hoc signed, not notarized; clean-machine testing remains in progress.

Update the CLI

itsy update

This updates your local command and bundled servers. It leaves your project files intact.

Update an existing server

From a site with that server saved as its deployment destination, run:

itsy update-server

This is separate from a CLI update. It asks before briefly restarting every site on the host. Comment metadata and Blog-only storage require server protocol 30, supplied by 0.22.0. Existing page-CMS sites must first be explicitly converted with verified backups; the server upgrade validates all installed sites and does not convert them.

Moving from Flea

Run flea update twice, or use the installer above, then use itsy for commands. Existing Flea-named site files continue to work without renaming.
