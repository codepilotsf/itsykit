ItsyWeb Guides

Server setup and deployment

Set up an Ubuntu host and publish committed source with automatic HTTPS.

Put your site online

ItsyWeb hosts multiple sites on one Ubuntu server. You'll need an Ubuntu host you control, SSH access, a domain pointing to that server, and inbound TCP ports 80 and 443 for HTTPS. ItsyWeb configures the web server on that host; it does not rent a server or create DNS records for you.

Set up the server

itsy setup

Run this from your computer and point it at a blank Ubuntu server over SSH. ItsyWeb installs the bundled server there and prepares the host to serve your sites. There is nothing to install by hand — no Go, Node, Python or database on the host. Use a server with ports 80 and 443 available for HTTPS.

Deploy a branch

Save your files, check the site with itsy status, and review and commit the changes.

itsy deploy

The first run asks for the server, domain and HTTPS preferences. It saves that branch's destination in itsy.config.json and offers to commit your reviewed files. Deployment publishes committed source and requires a clean working tree.

Each branch has its own destination. Use itsy deploy -configure to change it, or itsy https -configure to revisit just the HTTPS settings. Configuring a destination does not create DNS records.

ItsyWeb requests and renews Let's Encrypt certificates when HTTPS is enabled. There is no separate certificate tool to configure.

If you also use the optional on-page editor, see syncing live content before publishing content changes.

Temporary packaging storage

From 0.20.1, local packaging respects TMPDIR. If your Linux computer has a small RAM-backed /tmp, first check that /var/tmp is disk-backed, then use private scratch for one deployment:

(
  scratch=$(mktemp -d /var/tmp/itsy-job.XXXXXXXX) || exit 1
  trap 'rmdir -- "$scratch"' EXIT
  TMPDIR="$scratch" itsy deploy
)

The selected directory must exist and be writable. An invalid explicit setting fails without falling back elsewhere. Keep worktrees and retained screenshots or logs outside disposable scratch.
