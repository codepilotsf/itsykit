Server setup and deployment

Publish your site to an Ubuntu server with automatic HTTPS.

Set up Itsy Server

You'll need a supported Ubuntu LTS server, SSH access, and a domain pointing to it. Allow inbound TCP ports 80 and 443, then run this from your computer:

itsy setup

Follow the prompts to install Itsy Server on your Ubuntu host. One Itsy Server can host several sites.

Publish the site

Review and commit your project changes, then deploy from the site folder:

itsy status
git add .
git commit -m "Prepare site for publishing"
itsy deploy

The first deployment asks for the server, domain, and HTTPS preferences. It saves the destination for this Git branch in itsy.config.json. Commit the saved settings when prompted; in a larger repository, commit them manually and run deploy again.

Itsy publishes the committed files. Itsy Server serves the site and manages the Let's Encrypt certificate and renewal.

Use another destination

Each branch can have its own destination, such as a staging domain. To change the current branch's saved destination:

itsy deploy --configure

To list deployed sites or take an old site offline, see server management commands. The CLI reference lists all deployment options.

Keep live content

Normal deployment updates templates, assets, page metadata, and CSS while preserving live Blog posts and cover photos. To bring Blog content into your local project, use Blog content sync.
