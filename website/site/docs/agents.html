Working with coding agents

Use a coding agent to build pages or add features using the project’s own instructions.

Work in the project

Open the site folder with your agent and have it read AGENTS.md. Generated projects include skills for site authoring, design, and common additions.

Give it a concrete task:

Add a Visit page with our opening hours and a link in the navigation.
Keep the existing design.

Keep page copy in HTML, page metadata in leading settings comments, and shared lists in JSON data. Blog retains its admin editor and content storage. Review the files and preview the site before publishing.

Add a feature

Requests such as “add a blog” or “add a contact form” route to the focused guides in itsy/skills/. For an existing website, the import guide helps inventory its content, assets, and URLs.

These are portable Markdown instructions. The agent can read them without a plugin or account. They stay in Git but are excluded from public serving and deployment.

Existing projects

CLI updates leave project instructions untouched. To adopt newer skills, copy them from a freshly generated site and keep your project's own rules.
