Working with coding agents

Use the bundled site, import, Blog, and Contact instructions with a coding agent.

AI-assisted development

ItsyWeb projects include portable instructions so coding agents can follow the site's conventions and preserve existing content. For a focused addition, ask your agent to “add a blog”, “let's create a blog” or “add a contact form”. The project's AGENTS.md directs it to the matching skill.

The two setup skills ship in newly generated sites from 0.15.1. The public installer downloads 0.21.0. Blog requires 0.15.0 or newer; 0.21.0 uses server protocol 29.

  • itsy/skills/add-blog/SKILL.md covers Blog setup, private list/post templates, navigation, post JSON, drafts and publishing. It documents blog.data.posts, blog.data.post and the exact rich-body directive {blog.data.post.body}.
  • itsy/skills/add-contact-form/SKILL.md covers Contact setup, the form and thank-you page, exact field names, {csrf}, contact.data.*, contact.invalid.*, contact.error and contact.flash.notice. It also explains private email templates and local email previews.
  • itsy/skills/import-brochure/SKILL.md guides imports and redesigns through content inventory, two design directions, a sample page, local assets and editable snips.
  • .agents/skills/itsy-site/SKILL.md covers research-first site building, plus old-site URL inventories and verified 301 mappings. Its migration workflow can run on its own without a redesign.

A focused Blog or Contact addition follows your existing design without restarting a full-site consultation. Agents read the Markdown instructions; no plugin, account or runtime keyword listener is required.

Use the skills in an existing project

A CLI update leaves your project's files intact. Generate a disposable site with a matching 0.15.1-or-newer CLI, then copy itsy/skills/add-blog/ and itsy/skills/add-contact-form/ into your project. Add the matching request routes to your own AGENTS.md, preserving its custom rules. You can also point an agent directly at either SKILL.md.

These guidance files stay in Git but are excluded from public serving and deployment. A skill does not grant permission to publish posts, send real test mail or deploy.
