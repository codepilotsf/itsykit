Backups and recovery

Back up a site, recover code or content, and understand what each operation preserves.

Backups & recovery

Make a backup

itsy backup ../before-redesign.itsy-backup

This downloads the active site's code and editable content, including managed media and source CSS. Choose a new file path outside your site and keep a separate copy. Credentials, certificates, deployment mappings, host indexing policies and sessions are excluded.

Roll back code

itsy rollback --list
itsy rollback

Rollback republishes earlier code and CSS while retaining current admin content and host indexing policy. It asks for confirmation before acting.

Restore a backup

itsy restore ../before-redesign.itsy-backup

Restore replaces live code, site configuration and editable content while retaining current host indexing policy. It requires typed confirmation. Take a fresh backup first if newer content matters.

Reset a local project

itsy reset returns the local site to a clean starting point after confirmation. It replaces local files and settings, keeping Git history and a private sibling backup. It does not reset a live site.
