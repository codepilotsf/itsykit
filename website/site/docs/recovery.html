Backups and recovery

Back up the live site, return to earlier code, or restore saved content.

Make a backup

From the site folder, save a backup outside the project:

itsy backup ../bookshop.itsy-backup

It includes the active code, configuration, Blog posts, and cover photos. Keep another copy somewhere safe. Credentials, sessions, and custom app storage are excluded.

Roll back code

itsy rollback --list
itsy rollback

Choose a release and confirm. Rollback restores its code and CSS while keeping current Blog posts and cover photos.

Restore a backup

itsy restore ../bookshop.itsy-backup

Restore replaces code and content with the backup's versions after typed confirmation. Take a fresh backup first if you need to keep newer work.

Rollback and restore preserve Itsy Server's current host indexing policy.

Reset a local project

Stop dev, then run itsy reset to start the local site over. It replaces all local files and settings except Git history after confirmation, and keeps a private sibling backup. It does not change the live site.
