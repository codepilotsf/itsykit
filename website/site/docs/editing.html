ItsyWeb Guides

On-page editing

Let an admin edit selected content on the website while you keep control of its HTML and design.

Make text editable

Add a bare snip attribute to an element:

<section snip>
  <h2>A good place to find your next read.</h2>
  <p>Drop in and browse our shelves.</p>
</section>

Save while dev is running. ItsyWeb moves the content to itsy/snips.json and replaces it in the template with a generated reference. Keep that reference unchanged.

Mark whole content regions, without nesting snips. Leave navigation, form controls, and template instructions outside them.

Add an admin

itsy admin admin@example.com

The admin signs in at /admin with an emailed code. Dev previews the email locally; the live site needs HTTPS and email delivery.

Commit and deploy the admin-list change before sharing the live sign-in link.

Edit and save

Sign in, click the content, and make your changes. Use Save to publish or Cancel to return to the last save. Page details edits the page title and description.

Styles stay in your source CSS. Admins edit the content you've designated.

Bring live edits into your project

Normal deployment preserves admin edits. To download the current content and referenced media, stop dev and run:

itsy pull

Review and commit the result. To publish intentional local content changes after a pull:

itsy deploy --with-snips

If both sides changed, ItsyWeb asks which version to keep.
