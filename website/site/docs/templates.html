ItsyWeb Guides

Pages, layouts and data

Create pages, share markup, and bring JSON data into your HTML.

Pages and URLs

Put public pages and assets in site/. Page URLs leave off the file extension:

Project filesPublic URL
  • site/
    • index.html/
    • visit.html/visit
    • books/
      • index.html/books
    • images/
      • shop.jpg/images/shop.jpg

Link to /visit, without .html or a trailing slash. Files beginning with an underscore are private templates.

Layouts

site/main.layout.html supplies the document around each page. The page appears at {slot}:

<header>Little Bookshop</header>
<main>{slot}</main>
<footer>Independent books. Curious readers.</footer>

This illustrates the shared pieces. When editing the generated layout, keep its HTML document, admin conditionals, CSRF meta tag, and toolbar include.

Create site/shop.layout.html with its own {slot}, then select it at the start of a page:

<!-- itsy
layout: /shop.layout.html
-->

Partials

Save reusable markup in an underscore-prefixed file, such as site/_hours.html. Include it with:

{render hours}

Names resolve beside the calling template. Use {render /shared/hours} for site/shared/_hours.html.

Settings and JSON data

Public settings live under app in itsy.config.json. For example, {app.site_name} displays the site name.

Save lists and other structured data in itsy/data/. Create itsy/data/books.json:

{"items": [{"title": "A Field Guide to Birds"}, {"title": "The Quiet Garden"}]}

Loop over it in a page or partial:

{#each data.books.items as book}
  <p>{book.title}</p>
{:else}
  <p>New books are on their way.</p>
{/each}

Use conditions to show content when a value is present:

{#if app.phone}
  <a href="tel:{app.phone}">{app.phone}</a>
{/if}

{#unless app.phone} does the opposite. Conditions use values such as app.phone, rather than JavaScript expressions.

Page titles and descriptions

Give each page a title for the browser tab and a description for search results and link previews. Put them in an ItsyWeb page settings comment at the very top of the HTML file, before any markup:

<!-- itsy
title: Visit the bookshop
description: Find our opening hours and plan a visit to Little Bookshop.
-->
<section>
  <h1>Visit the bookshop</h1>
</section>

Write each setting as a single line of plain text, without quotation marks. You can include layout in the same comment when the page uses a custom layout.

In site/main.layout.html, use these values in the document head:

<title>{page.title} | {app.site_name}</title>
<meta name="description" content="{page.description}">

The comment supplies the page's defaults. Titles and descriptions saved through on-page editing live in itsy/snips.json and take precedence when nonempty. If no title is set, ItsyWeb uses the page's URL to make one.

Ordinary page text can stay in HTML. Use on-page editing for content an admin should change.
