Local development

Preview changes as you work, check your site, and test it on another device.

Run the local server

itsy dev

Run this from your project folder and open the Website URL it prints. Saving HTML, CSS, or content reloads the browser. Press Ctrl-C to stop.

Dev starts on port 3000 and chooses another if needed. To use a particular port:

itsy dev --port 4000

Running dev again replaces this project's existing dev server.

Test on another device

itsy dev --lan

Open a printed Network or Hostname URL on a phone or computer on the same trusted network. The full site works there, including Contact forms and Blog’s admin editor.

LAN previews use HTTP. Keep the development port private. Each device signs in separately; local email previews open on the computer running dev.

Check the project

itsy status

Status validates the site and shows its Git state. If the current branch has a saved deployment, it also checks that live site. It doesn't change your files.

Preview email

New sites open sign-in and Contact emails as private browser previews during development. You can use the sign-in code without configuring an email provider. Production uses real email delivery.

Start with examples

To explore a site with Team and Contact example pages:

itsy new --starter example-site

Use itsy new . to create a site in your current empty folder. For other options, run itsy new --help.
