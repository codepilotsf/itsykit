ItsyWeb Guides

Photos, videos and collections

Make photos, videos, and repeatable lists editable on the page.

Photos

Use ordinary image tags for developer-managed assets. Add snip when an admin should be able to replace one:

<img snip src="/images/shop.jpg"
  alt="Bookshelves at Little Bookshop"
  width="1200" height="800">

Start with a local JPEG or PNG. Dev imports it into managed media and creates its image and alt-text bindings. Keep dimensions and styling in the template.

In Edit mode, click the photo to choose or upload a replacement. Page Save publishes the change; Cancel discards it.

Videos

<video snip src="/videos/shop.mp4" controls></video>

Use a fast-start H.264 MP4, up to 25 MiB. ItsyWeb serves the file as supplied, without transcoding. Admins can replace the video or its poster from the page.

The video allowance is 64 MiB including retained replacements. Managed MP4s are Git-ignored; use itsy pull to retrieve them on another computer.

Collections

Use a multisnip for a list an admin should add to, remove from, or reorder. For example:

<article multisnip="team">
  <h2 snip="name">Sam Rivera</h2>
  <p snip="role">Bookseller</p>
  <img snip="photo" src="/images/sam.jpg" alt="Sam">
</article>

Dev turns this seed into a repeatable group. Admins use the on-page Add tile and drag handles, then save the page.

Keep collections on individual pages, with one root element per item. Text and photo fields are supported. For lists you maintain in code, use JSON data and a loop.
