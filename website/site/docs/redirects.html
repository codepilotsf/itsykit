Migration redirects

Keep old links working when you move a page or bring an existing site to ItsyWeb.

Map old paths to new pages

Add a top-level redirects object to itsy.config.json:

{
  "redirects": {
    "/about-us.html": "/about",
    "/opening-hours/": "/visit",
    "/old-team.php": "/about#team"
  }
}

Keep your other settings. Each source matches one exact path and returns a 301 for GET or HEAD requests. Point directly to an existing page or asset on your site.

List old extensions and trailing slashes explicitly. Wildcards and external destinations aren't supported.

Check the result

Run itsy status, then start dev. Check an old address using the local URL it prints:

curl -I http://localhost:3000/about-us.html

Look for 301 and Location: /about, then open the destination. Commit and deploy once the mappings are right.

Migrating a larger site

Give your agent the original URL and ask it to inventory pages and prepare redirects. Old sitemaps or URL exports help it find pages a live crawl might miss.

Keep useful addresses where possible and redirect moved pages to their closest replacement.
