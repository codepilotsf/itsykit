From a folder to a website.

These instructions assume Flea is installed. Download links and Homebrew installation instructions will be added when release artifacts have been published and verified.

1. Make a site

flea new my-project
cd my-project
flea dev

Choose the site name. Admin email and Resend setup are optional while developing. Open the local URL printed in your terminal.

2. Make some content editable

<article snip>
  <p>Tell people what you do.</p>
</article>

Save your file. Flea extracts the content into JSON and reloads the page. Approved admins sign in at /admin, then edit on the website itself.

3. Connect a contact form

Set contact.to in .flea.config.json, configure Resend with flea email, and restart dev. The starter includes contact and thank-you pages.

4. Deploy

flea deploy

Flea asks for the destination and checks the Git state. Use a disposable supported Ubuntu server while evaluating this development version. Normal deploys preserve live snips and theme settings.

Later, bring content back

flea pull

Stop dev first. Review and commit the downloaded snips and theme before continuing. Configuration and secrets aren't pulled.
