fleacms.com
terminal — blank server to live site
# install the CLI — no dependencies
$ curl -fsSL https://fleacms.com/install.sh | bash

# create a plain-HTML site
$ flea new my-site && cd my-site

# build the server over SSH
$ flea setup

# publish with automatic HTTPS
$ flea deploy
✔ deployed · Let's Encrypt HTTPS enabled
