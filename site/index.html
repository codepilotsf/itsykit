THE WHOLE SYSTEM

Not just a CMS.

Flea runs the whole trip: the binary on your machine, the server it builds, the deploy, the certificates, and the editing your clients do later.

  • {icon server}

    Builds your server

    Point flea setup at a blank Ubuntu box over SSH. Flea installs itself there and gets the host ready to serve. Nothing to install by hand.

  • {icon shield-check}

    HTTPS, handled

    Flea requests and renews Let's Encrypt certificates, redirects www, and serves every site over TLS.

  • {icon rocket}

    Deploy over SSH

    Publish a committed Git branch to your own server. One host can serve as many sites as you need.

  • {icon file-code}

    No build step

    Plain HTML and CSS with JSON content. No bundler, no database, no Node toolchain to keep alive.

  • {icon terminal}

    A real dev server

    Live reload, LAN testing, email previews and flea status for local and remote checks.

  • {icon history}

    Backups & rollback

    Download a complete backup, roll code back while keeping live content, and recover deliberately.

THE DEVELOPER'S SIDE

Your markup.
One attribute.

Add snip to any element. Flea moves the content into JSON, connects it to the on-page editor, and leaves your classes, layout and links untouched.

Repeatable lists use multisnip. Everything else stays developer-managed JSON and plain files you keep in Git.

Need a blog? Flea 0.15.0 adds draft posts, rich text and cover photos, with a documented JSON format for agents. See Blog setup and availability.

AI-FRIENDLY

Agents can build it with you.

Every Flea site ships portable instructions a coding agent understands. Point Claude Code, Codex or another agent at the repo and it can follow your conventions, import an existing site and keep editable content intact.

  • Skill files checked into Git beside your site
  • AGENTS.md guidance in every project
  • No plugin, account or special runtime required
  • Plain HTML out, so any agent can read it
agent sessionIMPORT A SITE

fetching pages, images and styles

The bundled import skill is plain Markdown. Bring your own agent.

THE ADMIN'S SIDE

Their website.

Admins sign in with an emailed code, click the text, photo or list they want to change, and save. Text, media and repeatable collections are editable on the page. You decide what they can touch.

START TO FINISH

Five commands to live.

Build locally. Let Flea prepare the server. Publish when you are ready.

Read the quickstart ↗
  1. 01

    Install the CLI

    One line. No Go, Node or Python to install first.

    curl -fsSL https://fleacms.com/install.sh | bash
  2. 02

    Start a site

    A clean folder of HTML, CSS and JSON. Your design, no build step.

    flea new my-site
cd my-site
  3. 03

    Build locally

    Live reload, editable content and validation while you work.

    flea dev
  4. 04

    Prepare the server

    Flea installs itself on a blank Ubuntu host over SSH.

    flea setup
  5. 05

    Publish

    Ship the branch and enable HTTPS. One host, many sites.

    flea deploy
